## Deploy

1. Fork / upload this repo to your GitHub.
2. Get your `SESSION_ID` from your session website.
3. Deploy on Railway / Heroku / Koyeb and set the `SESSION_ID` environment variable.
4. Set `OWNER_NUMBER` and `OWNER_NAME` in the environment variables.
